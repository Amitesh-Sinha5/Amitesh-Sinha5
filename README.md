## <img src="https://media.giphy.com/media/WUlplcMpOCEmTGBtBW/giphy.gif" width="28" /> Engineering Philosophy

> Getting a model to produce an answer is the easy part. Making it something people can **depend on** is the work.

I build systems where the interesting problems live *around* the model, not just inside it — retrieval that admits when it doesn't know, cost and latency you can actually see, guardrails that hold, and tests that fail when quality regresses rather than when a string changes.

Currently focused on **agentic AI infrastructure**: multi-agent orchestration, RAG that survives contact with real documents, and the backend plumbing that makes it deployable.

### 🧬 Helix — Agentic AI Operations Platform

<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" /> <img src="https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white" /> <img src="https://img.shields.io/badge/LangGraph-1C3C3C?style=flat-square" /> <img src="https://img.shields.io/badge/Kubernetes-326CE5?style=flat-square&logo=kubernetes&logoColor=white" />

Three LangGraph agent pods over one governed backend — the plumbing an AI *feature* needs to become an AI *product*.

- 🔍 **Hybrid RAG** — vector + BM25 fused with reciprocal rank fusion, reranked, with an agentic re-query loop
- 🚫 **Abstains instead of confabulating** — a groundedness validator rejects unsupported answers
- 🎯 **CI-enforced quality gate** — faithfulness `0.98`, relevance `0.73`, context precision `1.00`
- 🧠 **Trained classifier, not just prompting** — TF-IDF + logistic regression handles confident tickets at zero LLM cost
- 📊 **Cost telemetry on every call** — latency, tokens, spend, cache savings
- ✅ **199 tests** across pytest, Vitest and Playwright
